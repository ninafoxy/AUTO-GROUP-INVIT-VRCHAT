-Clone the repository locally.

```sh
git clone https://github.com/ninafoxy/AUTO-GROUP-INVIT-VRCHAT.git \
cd auto-group-invit
```

-Build the project.

```sh
cargo build --release
```

-Load VRChat cookies and group into the config file.

-Run the project.

```sh
./target/release/auto-group-invit
```
